# java-lotto-precourse

## 기능 목록
- [ ] 로또 구입 금액을 입력받고 1,000원 단위 여부를 검증한다.
- [ ] 구입 금액에 해당하는 개수만큼 로또 티켓을 자동 생성한다.
- [ ] 생성된 로또 번호를 오름차순으로 정렬하여 출력한다.
- [ ] 당첨 번호와 보너스 번호를 입력받고 형식을 검증한다.
- [ ] 당첨 번호와 보너스 번호로 추첨 결과를 계산한다.
- [ ] 각 등수별 당첨 개수를 집계하고 수익률을 계산한다.
- [ ] 잘못된 입력과 규칙 위반 시 `[ERROR]` 메시지를 출력하고 재입력을 요청한다.

## 실행 가이드
- Java 21 환경에서 `./gradlew clean test` 명령으로 테스트를 실행한다.
- `./gradlew run` 명령으로 애플리케이션을 실행한다.
